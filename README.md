# FIBOHEAP

Es una estructura que permite realizar operaciones eficientes con costo amortizado.

## Propiedades de los nodos:
- El valor de cada nodo es mayor o igual que el valor de su padre.
- Cada nodo tiene a lo sumo un hijo con el mismo grado que él.
- El grado de un nodo es igual al numero de hijos que tiene.

## Operaciones principales:

- **Insercion**: Agrega un nuevo nodo al Fiboheap.
- **Extraccion del minimo**: Extrae el nodo con el valor minimo del Fiboheap.
- **Disminucion de clave**: Disminuye el valor de un nodo existente en el Fiboheap.
- **Eliminar nodo**: Elimina cualquier nodo dentro de la estructura.
- **Union**: Combina dos Fiboheaps en uno solo.
- **FindMin**: Encuentra el nodo minimo.
- **Find Nodo**: Encuentra un nodo cualquiera
